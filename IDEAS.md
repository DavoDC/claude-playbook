# Ideas & Feature Planning

Active ideas and TODOs for this repo are kept in a private file in your own workspace repo, never in this repo.

That file uses the standard P0/P1/quick-wins format and feeds `/dev-session claude-playbook` directly. Completed work is logged in a private history file alongside it.

If you maintain your own playbook fork, keep your ideas in a private location (your workspace repo, a private gist, or a local file outside this repo) and add a pointer here.

For bug reports or public feature suggestions, open a GitHub Issue.
